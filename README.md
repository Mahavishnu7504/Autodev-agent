# Task Manager CLI

A simple command-line task manager built with the Python standard library.

## Features

- Add, list, complete, and delete tasks.
- Persist tasks in a local JSON file.
- Validate task IDs and empty descriptions.
- Recover from malformed JSON storage.
- Run automated unit tests.
- Execute a deterministic demo without interactive input.

## Requirements

Python 3.10 or later. No third-party packages required.

## Usage

Run the deterministic demo:

```bash
python -m app.main
